# Распределение автобусов по маршрутам с помощью RL

Командный курсовой проект по оптимизации работы городского общественного транспорта. Целевой город для поиска данных — Нижний Новгород.

## Цель

Исследовать, может ли обучение с подкреплением (RL) улучшать план распределения ограниченного парка автобусов между фиксированными маршрутами по периодам дня эффективнее классических методов поиска.

Пользу плана предполагается оценивать по ожиданию пассажиров, переполненности и качеству обслуживания отдельных маршрутов при одинаковых ресурсах.

## Подход

1. Подготовить данные о маршрутах, остановках, спросе и времени движения. При нехватке истории использовать явно обозначенные синтетические сценарии.
2. Построить динамическую модель: пассажиры приходят и ожидают, автобусы выполняют рейсы, посадка ограничена вместимостью.
3. Создать начальный план и проверять исполнимость назначений с учётом завершения рейсов и переездов.
4. Обучить RL-агента выбирать изменения готового плана, получая обратную связь от симулятора.
5. Сравнить RL с обычным поиском при одинаковом бюджете симуляций, отдельно учитывая стоимость обучения.

В основной постановке маршруты остаются фиксированными. Планирование частот и отправлений входит в задачу; оперативное управление удержанием автобусов и перестройка маршрутов — возможные расширения.
