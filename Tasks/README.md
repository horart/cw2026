## Общий формат результатов первого этапа

- Текст со ссылками на первоисточники.
- Для отдельных релевантных разделов — указание страниц или секций.
- Markdown на GitHub либо текст в сообщениях.
- Устный рассказ на встрече.

21 октября встреча планировалась ориентировочно через неделю. Позднее её согласовали на 29 октября; письменные материалы просили прислать до встречи. Отдельный срок для уточнения от 29 октября не указан.
